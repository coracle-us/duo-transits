METHOD
------
* Blind box search of every light curve (s04_find_events.py) -> events.
* Each event fitted with a trapezoid (free t0, depth, T14, ingress, local quadratic baseline, exposure
  -time integration) in each independent reduction (s06_fit_events.py). t0 error = max(scaled
  covariance, prayer-bead); per-event error = max(median per-source error, scatter between sources).
* Candidate periods = (longest same-type baseline)/N, kept if all other event times match within
  5 sigma + 0.005 d; then linear ephemeris fit (s09_run_periods.py).
* "Covered and flat" test (s08_periods.py): at each predicted epoch, in each data set, fit a linear
  baseline to points 0.6-0.6+Bw T14 away, measure the mean in-eclipse deficit, compare with the
  trapezoid model evaluated at the ACTUAL in-eclipse time stamps (so partial ingress/egress coverage
  is handled), using an empirical sigma from 300 random epochs in the same data set (includes red
  noise). FLAT = expected - measured > 5 sigma and measured < 0.5 x expected with >= 3 in-eclipse
  points; the predicted time is scanned over +-3 sigma_pred. A period is excluded if some epoch is
  FLAT in a data set and no data set shows an EVENT there. TESS-based exclusions for 212694013 were
  then checked by eye (plots/tess_alias_epochs_212694013.png) and down-graded where marginal.
* Secondary search at all phases, durations 0.5-2 x T14 (s11_secondary.py).

None of these predicts an eclipse in TESS S72 or S1751 (all predicted epochs fall in gaps), so
  TESS does not split them. TESS S44/S46 contain no data on this star (off silicon).
Secondary: none found. For P = 44.06, 55.08, 73.44 d the phase coverage is 100% and no dip
  deeper than ~0.1% (best 5.9-7.6 sigma features are K2 systematics); 67% coverage for 110.16 d,

  primary and secondary at phase 0.5: 88.129, 110.161, 146.881, 220.322 or 440.644 d.
  (For P = 220.32 the C18 event falls at an odd cycle, so it would be the "secondary" of 440.64 d.)
  If not a twin, the absence of any secondary at full phase coverage (P <= 73.4 d) means a cool/dark
  companion.
Confidence: HIGH that the three events are the same body and P is one of the 5 aliases (or 2x);
  period NOT resolved. The 3.9-h duration is short for any of these periods on a K dwarf -> high
  impact parameter / grazing, so a 20%-deep event here is more likely stellar than planetary.
